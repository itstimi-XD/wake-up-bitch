# Solo vs Party Mode - 모드 시스템 설계

## 개요

Wake Up Bitch는 **혼자서도, 친구들과도** 즐길 수 있도록 두 가지 모드를 제공합니다.

interface Goal {
  id: string;
  title: string;
  target: number;
  current: number;
  deadline?: Date;
}

interface Challenge {

## 포인트 시스템

### 포인트 획득

| 행동 | 포인트 |
|------|--------|
| 알람 성공 | +10P |
| 연속 7일 성공 | +50P |
| 연속 30일 성공 | +200P |
| 챌린지 승리 (1:1) | +내기 포인트 |
| 챌린지 승리 (그룹) | +총 포인트 / 참가자 수 |

### 포인트 사용

| 항목 | 포인트 |
|------|--------|
| 챌린지 내기 | -내기 포인트 |
| 프로필 커스터마이징 | -100P ~ 500P |
| 특수 알람 사운드 | -200P |

## 친구 시스템

### 친구 추가 방법

1. **검색으로 추가**
   ```
   검색창에 이메일/닉네임 입력
   → 친구 요청
   → 상대방 수락
   ```

2. **QR 코드**
   ```
   내 QR 코드 생성
   → 친구가 스캔
   → 즉시 친구 추가
   ```

3. **연락처 동기화** (선택사항)
   ```
   연락처 권한 허용
   → 앱 사용 중인 친구 자동 추천
   ```

## 알림 시스템

### Solo Mode 알림
- ⏰ 알람 시간 (로컬)
- 🎯 목표 달성 알림
- 🏆 뱃지 획득 알림

### Party Mode 알림
- 👥 친구 요청
- 🎉 챌린지 초대
- 📊 챌린지 결과
- 🏆 순위 변동
- 💰 포인트 획득/손실

---

## 추천 UX 플로우

### 신규 사용자

1. 앱 다운로드
2. 회원가입
3. **Solo Mode로 시작** (튜토리얼)
4. 첫 알람 설정
5. 미션 체험
6. 성공 후 → "친구와 함께하면 더 재미있어요!" 팝업
7. Party Mode 소개
8. 친구 추가 유도

### 기존 사용자

```
Solo Mode ⇄ Party Mode
     ↓           ↓
  개인 목표   친구 경쟁
     ↓           ↓
   성장      포인트 획득
```

두 모드를 자유롭게 오가며 사용

## 향후 확장

### Solo Mode
- AI 코치 (개인 맞춤 조언)
- 수면 패턴 분석
- 건강 데이터 연동

### Party Mode
- 길드 시스템 (팀 대항전)
- 시즌제 리그
- 토너먼트
- 친구 초대 보상

---

**결론:** Solo Mode로 습관을 만들고, Party Mode로 동기부여를 극대화! 🔥
