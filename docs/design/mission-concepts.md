# Wake Up Bitch - 독창적인 기상 미션 컨셉

## 미션 철학

"Wake Up Bitch"는 단순히 알람을 끄는 것이 아니라,
**진짜로 깨어있는 상태**로 만들고 **하루를 시작할 동기부여**를 주는 것을 목표로 합니다.

## 8가지 독창적 미션

### 1. BOSS_FIGHT (보스 레이드)
**컨셉**: "아침은 전쟁이다!"

- 보스 몬스터가 등장하고 연타로 공격
- HP 바를 0으로 만들어야 알람 종료
- 난이도별로 HP와 필요 탭 수 증가
- 게이미피케이션으로 재미 요소 추가

**기술 구현**:
- 터치 이벤트 감지
- 애니메이션 효과
- 진동 피드백

---

### 2. REALITY_CHECK (현실 직시)
**컨셉**: "오늘 할 일이 뭐야?"

- 오늘 해야 할 일 3가지 입력
- 시간대별 목표 설정 (오전/오후/저녁)
- 저녁에 완료 여부 체크 알림
- 생산성 추적 및 통계

**기술 구현**:
- 텍스트 입력 검증
- 알림 스케줄링
- 할 일 관리 DB

---

### 3. MONEY_TIME (돈 벌 시간)
**컨셉**: "시간은 돈이다!"

- 사용자의 시급/월급 설정
- "10분 더 자면 X원 손해!" 계산
- 간단한 돈 계산 문제 풀기
- 연봉으로 환산한 손실액 표시

**기술 구현**:
- 수학 문제 생성 엔진
- 사용자 급여 정보 저장
- 시간 계산 로직

---

### 4. SLAP_AWAKE (정신차려!)
**컨셉**: "스스로를 깨워라!"

- 화면을 연속으로 때리기 (rapid tap)
- "정신차려!" 문구와 함께 강렬한 비주얼
- 콤보 시스템 (연속 타격)
- 진동과 사운드로 각성 효과

**기술 구현**:
- 멀티터치 감지
- 터치 속도 측정
- 햅틱 피드백

---

### 5. SELFIE_ROAST (셀프 디스)
**컨셉**: "거울 보고 일어나!"

- 전면 카메라로 셀카 촬영
- "일어나, 보기 싫어!" 같은 동기부여 메시지 선택
- 사진과 함께 각성 메시지 저장
- 주간 리뷰에서 사진 모음 확인

**기술 구현**:
- 카메라 API
- 이미지 저장
- 재미있는 메시지 DB

---

### 6. VOICE_POWER (외쳐라!)
**컨셉**: "크게 외치면 깬다!"

- 동기부여 문구를 큰 소리로 읽기
- 음성 인식으로 정확도 측정
- "I'm gonna work, bitch!" 같은 파워풀한 문구
- 목소리 크기 측정

**기술 구현**:
- 음성 인식 (Speech-to-Text)
- 볼륨 레벨 측정
- 문구 매칭 알고리즘

---

### 7. POWER_WALK (파워워킹)
**컨셉**: "걸어서 출근 준비!"

- 30걸음 걷기 (실내/화장실/부엌)
- 만보기 센서 활용
- 걸음 수 실시간 표시
- 움직여야만 알람 종료

**기술 구현**:
- 가속도계/만보기 센서
- 걸음 수 감지 알고리즘
- 부정행위 방지 (흔들기 vs 진짜 걷기)

---

### 8. COFFEE_RUN (카페인 충전)
**컨셉**: "커피 머신 앞까지 가!"

- 특정 장소 등록 (커피머신, 부엌 등)
- GPS/비콘으로 위치 확인
- 사진 촬영으로 2차 인증
- 실제로 움직여야 끌 수 있음

**기술 구현**:
- 위치 기반 서비스
- 카메라 인증
- 사전 등록된 위치 매칭

---

## 난이도 시스템

### EASY (쉬움)
- 짧은 시간
- 적은 요구사항
- 초보자 친화적

### MEDIUM (보통)
- 중간 난이도
- 적절한 도전

### HARD (어려움)
- 확실하게 깨움
- 높은 요구사항
- 진짜 일어나지 않으면 불가능

### INSANE (미친난이도)
- 미션 2개 이상 조합
- 최고 난이도
- "진짜 일어날 각오 됐어?"

---

## 미션 조합 시스템

사용자는 여러 미션을 순차적으로 설정 가능:
```
1. SLAP_AWAKE (화면 때리기)
2. REALITY_CHECK (오늘 할 일 입력)
3. POWER_WALK (30걸음 걷기)
```

이렇게 하면 **절대 다시 못 잔다!**

## 통계 및 동기부여

- 기상 성공률
- 가장 많이 실패한 미션

- "아침형 인간 인증"

4. **재미**: 짜증나지만 재미있게
