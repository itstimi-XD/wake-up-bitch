## 데이터 구조

### User Financial Profile
```typescript
interface UserFinancialProfile {
  userId: string;

  // 수입
  income: {
    salary: number;          // 월급
    sideHustle: number;      // 부업
    other: number;           // 기타
    total: number;           // 총합
  };

  // 고정 지출
  fixedExpenses: {
    rent: number;            // 월세/대출
    utilities: number;       // 통신비
    insurance: number;       // 보험
    loan: number;            // 대출
    subscriptions: number;   // 구독
    transportation: number;  // 교통비
    other: number;           // 기타
    total: number;           // 총합
  };

  // 카드
  creditCard: {
    thisMonthSpent: number;  // 이번 달 사용액
    paymentDay: number;      // 결제일
  };

  // 계산값
  calculated: {
    dailyExpense: number;    // 일평균 지출
    hourlyExpense: number;   // 시간당 지출
    minuteExpense: number;   // 분당 지출
    disposableIncome: number; // 가처분소득
  };

  // 목표
  goals: {
    savingsTarget: number;   // 저축 목표
    deadline: Date;          // 목표일
  };

  updatedAt: Date;
}
```

## 동기부여 메시지 시스템

### 상황별 메시지

#### 월급날 이후 (1-7일)
```
"이번 달도 시작됐어! 계획대로 써!"
"월급 들어온 지 3일... 아직 여유 있지?"
```

#### 중순 (8-20일)
```
"벌써 절반 지났어, 페이스 조절해!"
"아직 카드값 {금액}원 남았어!"
```

#### 월말 (21-30일)
```
"월세 {D-day}일 남음! 준비됐어?"
"이번 달 {잔액}원 남았어. 절약 모드!"
```

#### 카드 결제일 임박
```
"D-3! 카드값 {금액}원 준비했어?"
"내일 카드값 나가! {부족액}원 부족!"
```

#### 마이너스 상황
```
"⚠️ 위험! 예산 초과 중!"
"이번 달 {초과액}원 초과했어!"
"절약하거나... 더 벌거나!"
```

### 톤 & 매너

- **현실적이지만 너무 우울하지 않게**
- **동기부여 + 약간의 유머**
- **구체적인 숫자로 명확하게**

예시:
```
❌ "돈이 부족해요"
✅ "D-5일! 아직 32만원 필요해!"

❌ "열심히 일하세요"
✅ "오늘 7만원 벌면 월세 걱정 끝!"

❌ "지출을 줄이세요"
✅ "스벅 3번 참으면 = 15,000원 절약!"
```
